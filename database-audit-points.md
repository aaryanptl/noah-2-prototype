# Database audit points

## Test and question serving

- Check the sequence in which topics are served during tests.
- Check whether the current logic covers all required learning objectives and questions.
- Check whether the correct question type, topic, grade and difficulty are being served.
- Check whether the same question is served more than once in a session.
- Check whether repeat policies are working as expected.
- Check whether any questions are missing an answer, have blank options, duplicate options or broken media.
- Check whether questions marked as hard are actually difficult for students.
- Check whether some questions have almost no correct answers.
- Check whether one wrong option is selected more often than the correct answer.
- Check whether some answer options are never selected.

## Student performance and mastery

- Check the student mastery score based on the current data.
- Check whether scores are consistent across tests for the same student and topic.
- Check whether students improve after a practice test.
- Check whether students improve after their second or later attempt.
- Check response speed and flag answers submitted unusually quickly.
- Check whether repeated fast, incorrect answers are affecting the accuracy results.
- Check where students spend the most time but achieve the lowest scores.
- Check performance by thinking level, such as remember, understand, apply and analyse.
- Check whether weak performance is limited to a topic, learning objective, test type or student group.

## Completion and fatigue

- Compare the number of students who start a test with the number who finish it.
- Check where students stop during a test.
- Check whether accuracy drops as the test gets longer.
- Check skipped questions, timeouts and long struggles separately from incorrect answers.
- Check whether long homework or practice sessions lead to lower accuracy.

## Audit rules

- Use a minimum attempt count before calling a question or pattern problematic.
- Keep skips, timeouts, guesses and wrong answers as separate types of evidence.
- Compare similar groups instead of using one benchmark for every student.
- Keep the original data unchanged.
- Record the evidence, finding, confidence level, recommended action and owner for every issue.
