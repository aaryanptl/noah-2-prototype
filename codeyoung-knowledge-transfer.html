01 / Learning platform

The work

Assessment

Math placement test

Grade-level assessment, regional content, topic insights and result reporting.

Assessment

Topic & multi-topic tests

Test mastery within one topic or across several topics.

Adaptive logic adjusts difficulty live as the student answers: two correct in a row moves up a band, an incorrect answer moves down, and a partial answer holds while breaking the streak. Attempts and hints grade each answer, so a clean first try counts differently from one solved after multiple tries or a reveal.

Practice

Math practice

Self-learning flow with topic practice, hints, adaptive serving and next suggestions.

Homework

Math homework

Question content, schema, backend serving, difficulty modes and frontend integration.

English

Quality
